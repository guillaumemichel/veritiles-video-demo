Verified video from an untrusted host

This player streams video — Big Buck Bunny by default — over plain HTTP range requests and cryptographically verifies every byte against a single veritiles anchor CID before the decoder sees it. The host is untrusted: flip the switch below to route reads through a mirror serving tampered bytes — they are caught, counted, and never rendered.

Paste any anchor CID and the URL of a file packed with veritiles; proofs are read from <url>.proofs/.

How it works

The page ships one trust input: the anchor CID in the field above. The video's proof — a tiny descriptor plus a shard of leaf digests — is a directory of static files beside it (<url>.proofs/); the client fetches only the pieces covering what it reads and verifies each 1 MiB leaf with WebCrypto sha2-256 before use. From the first verified leaf the player reads the codecs off the fragmented MP4's moov and the segment list off its global sidx, then streams moof/mdat segments into Media Source Extensions with ~30 s of buffer ahead; seeking jumps the read cursor. A source whose bytes fail verification is dropped for the rest of the session and the next one takes over.
