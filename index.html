Verified video from an untrusted host

This player streams Big Buck Bunny over plain HTTP range requests and cryptographically verifies every byte against a single veritiles anchor CID before the decoder sees it. The host is untrusted: flip the switch below to route reads through a mirror serving tampered bytes — they are caught, counted, and never rendered.

sourcerequeststransferredstatus

How it works

The page ships one trust input, the anchor CID . The video's proof — a tiny descriptor plus a shard of leaf digests — is a directory of static files beside it; the client fetches only the pieces covering what it reads and verifies each 1 MiB leaf with WebCrypto sha2-256 before use. The player parses the fragmented MP4's global sidx from the first verified leaf and streams moof/mdat segments into Media Source Extensions with ~30 s of buffer ahead; seeking jumps the read cursor. A source whose bytes fail verification is dropped for the rest of the session and the next one takes over.
